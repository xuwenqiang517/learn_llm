## 三、回测逻辑详细设计

### 3.1 每日流程

```
for date in trading_dates:
    # 1. 卖出检查 (T+1限制)
    for position in positions:
        if position.hold_days >= 1:  # T+1限制
            if meets_sell_condition(position, date):
                sell(position, date)
    
    # 2. 选股 (使用前一日收盘后数据)
    selected_stocks = run_selection(prev_date=date)
    
    # 3. 买入 (按开盘价)
    for stock in selected_stocks:
        if len(positions) < max_positions:
            buy(stock, date, open_price)
    
    # 4. 记录日志
    log_daily_report(date, positions, trades, selections)
```

### 3.2 卖出条件判定

```python
def check_sell_condition(position, date, data) -> Tuple[bool, str]:
    """检查是否满足卖出条件"""
    # 条件1: 最近1天跌幅超过5%
    daily_change = get_daily_change(position.code, date)
    if daily_change <= -5.0:
        return True, f"单日跌幅{daily_change:.2f}%"
    
    # 条件2: 连续2天跌幅超过5%
    consecutive_drops = get_consecutive_drops(position.code, date)
    if consecutive_drops >= 2:
        return True, f"连续{consecutive_drops}天下跌"
    
    return False, ""
```
